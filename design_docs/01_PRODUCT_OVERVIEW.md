Business Idea

A parcel forwarding service for NRIs.

We help customers outside India to:

Buy products from Indian websites (Amazon, Flipkart, Myntra etc)
Buy products from offline Indian shops
Consolidate multiple orders into one shipment
Pack and ship internationally

Core Features (MVP)
1️⃣ User Account

Users can:

Signup
Login
Verify email
Manage address
View orders
2️⃣ Create Purchase Request

User can request us to buy products for them.

Two types of requests:

Online Purchase

User provides:

Product URL
Size
Color
Quantity
Notes
Offline Purchase

User provides:

Product photo/screenshot
Description
Quantity
Notes
3️⃣ Order Workflow

Master Order → contains multiple items

Status Flow:

REQUESTED
→ REVIEWING
→ PAYMENT_PENDING
→ PURCHASED
→ RECEIVED_AT_WAREHOUSE
→ PACKING
→ SHIPPED
→ DELIVERED
4️⃣ Payments

User pays after we review order and give quotation.

We will support:

International payments
Multi-currency

Planned provider:

Wise (primary)
Stripe (future)
5️⃣ Parcel Consolidation

Multiple orders → single shipment.

This is key differentiator.

6️⃣ Tracking System

User can track:

Order progress
Sub-orders/items
Shipment tracking number
7️⃣ Admin Panel (Internal)

Admin can:

View users
Review orders
Add price quotation
Update order status
Add tracking numbers
